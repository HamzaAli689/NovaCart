# 🛒 NovaCart — Modern E-Commerce Mobile Application

NovaCart is a high-performance, feature-rich e-commerce mobile application built using **Flutter** and **Dart**. Designed with a modern dark navy and vibrant orange aesthetic, it delivers a seamless shopping experience with smooth state management and a clean architecture.
---

## ✨ Key Features

- **⚡ GetX State Management:** Fast, reactive, and efficient state handling across the app.
- **🎨 Dynamic Theme Engine:** Seamless switching between Dark Mode and Light Mode with custom-tailored palettes.
- **🛍️ Marketplace & Categories:** Browse products dynamically across categories like Electronics, Fashion, Shoes, and more.
- **❤️ Interactive Wishlist & Cart System:** Real-time calculation of subtotal, shipping fees, and item quantity management.
- **📦 Single-Page Checkout Flow:** Streamlined checkout experience integrating shipping address and payment methods.
- **🔥 Firebase Backend Integration:** User authentication (Sign-up/Login) and secure Firestore cloud database synchronization.
- **📱 Clean Architecture:** Structured codebase ensuring high scalability and maintainability.

---

## 🛠️ Tech Stack & Packages

- **Framework:** Flutter (Dart)
- **State Management:** GetX
- **Local Storage:** GetStorage, Hive
- **Backend & Database:** Firebase Authentication, Cloud Firestore, Firebase Storage
- **UI Components:** Glassmorphic elements, custom custom cards, and responsive layouts.
